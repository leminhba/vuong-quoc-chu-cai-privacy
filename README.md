# Chính sách quyền riêng tư — Vương Quốc Chữ Cái

Trang chính sách công khai của Mây-Bột Studio. Hỗ trợ: leminhba@yahoo.com.

Repository này chỉ chứa trang chính sách; không chứa mã nguồn game hoặc dữ liệu người chơi.

Để xuất bản: Settings → Pages → Deploy from a branch → main → /(root) → Save.

Nguồn nội dung được quản lý trong dự án game: src/legal/privacy-body.html và src/legal/release.json.
Sau khi sửa chính sách trong dự án game, chạy npm run build, node tools/privacy-site.mjs và cập nhật hai tệp HTML ở đây.
